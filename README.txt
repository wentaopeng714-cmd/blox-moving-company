摇摇搬家队 — 持续营业移动版

独立运行的 3D Blox 搬运小游戏，明亮色块、分层明暗与彩色暗部。

核心循环：
1. 一车装着三件待交付家具与两件备用货，跟随路标推车。
2. 绿植会洒水、冰箱门会甩开、沙发坐垫会弹起；过坎、急转时及时扶稳。
3. 到目标绿圈停稳、松开摇杆，按住按钮完成卸货，家具进入房间、居民回应。
4. 三户送达后不会结束。带着两件备用货返仓，按住接单，家具逐件叠回车上。
5. 每批轮换家具顺序，累计送达、收入及照护状态保留，可以一直营业。

新委托约每 38 秒有效游戏时间出现一次，最多暂存一批，不连续弹单催促。
按住扶稳会消耗握力，松开恢复；到站按同一个按钮卸货或装车。
没有强制倒计时、复杂经营、多人联网。三条街区可在菜单中切换。
刷新保存本街区已送货物、收入、当前批次和返仓道路进度。

手机：左下角摇杆推车/转向，右下角按住扶稳或停稳后操作。
电脑：WASD/方向键移动，空格扶稳或站点操作，R 回最近交付点。
菜单与页面后台暂停；支持竖屏和横屏、安全区和指针取消。

运行：本文件夹执行 npm start，访问 http://localhost:4182/ 。
也可通过任意静态 HTTP 服务器部署本文件夹，不要直接双击 index.html。

入口 index.html；main.js 负责场景和交互；engine.js 为规则；personality.js 为家具、居民和装卸表现；art.js 为程序化 3D 美术工具。
Three.js 包含在 vendor，许可证见 vendor/THREE-LICENSE.txt。

验证：22 项规则检查通过，包括六种路线/货物组合、三条返程、接单频率、库存、收入、存档与碰撞。
浏览器实际完成交付、返仓、再接单和重新装货，检查 400×580 与 320×568 布局。
未在实体手机上验证性能、震动或实际扬声器听感。美术为程序化模型，不包含外部商业资产。
